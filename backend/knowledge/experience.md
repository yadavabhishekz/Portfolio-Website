## Internship: AI Intern at Barco Electronic Systems Pvt Ltd (Product Security Team)

## What I built at Barco
- Engineered an AI-powered threat modeling tool using Python, Streamlit, and the STRIDE methodology, reducing security assessment time by 70% and identifying 85%+ of vulnerabilities automatically.
- Designed threat identification pipelines and automatic attack tree generation.
- Orchestrated the integration of 4 LLM APIs (OpenAI, Claude, Gemini, Mistral) so the tool wasn't locked into one model, generating 50+ threat models and attack trees weekly.
- Delivered a containerized solution with Docker that generates downloadable security reports in Markdown and PDF.

## What I learned at Barco
